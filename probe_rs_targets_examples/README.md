# 自定义芯片定义文件示例

本目录包含 probe-rs 官方不支持的芯片定义文件示例。

## 使用方法

1. 复制所需的 `.yaml` 文件到程序运行目录下的 `probe_rs_targets` 目录
2. 重启程序后即可在芯片列表中看到自定义芯片

## 目录说明

- `probe_rs_targets` - 程序运行时读取的目录（需手动创建或复制文件到此）
- `probe_rs_targets_examples` - 示例文件存放目录（本目录，不会被打包）

## 注意事项

- 本目录仅供参考，不会被打包到发布版本中
- 如需使用，请手动复制文件到运行目录的 `probe_rs_targets` 目录
- 芯片定义文件格式请参考 probe-rs 官方文档
