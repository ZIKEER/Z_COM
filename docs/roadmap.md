# 功能状态与路线图

## 状态定义

- **已实现**：当前 Rust 版本已经具备，可进入实际测试。
- **待完善**：已有基础实现，但行为、兼容性或交互尚未达到目标。
- **待实机验收**：代码、检查或构建已完成，但仍需要真实系统或硬件验证。
- **计划支持**：需求已确认，等待实现。
- **暂不支持**：当前阶段明确不做。

## 已实现

详细行为见 [使用与功能说明](user-guide.md)。

- 串口、TCP/UDP Client/Server 和双后端 RTT 通信。
- 串口运行时参数调整与手动波特率输入。
- J-Link SDK 动态发现、手动选择和缺失时降级。
- probe-rs 自定义 MCU YAML、指定 MCU RTT 和可选通用 FTDI/JTAG 显示。
- HEX、ASCII、HEX+ASCII、ANSI 颜色和通信事件显示。
- 普通发送、自动发送、扩展发送与输入校验。
- 按日期自动日志、配置持久化和绿色版相对目录。
- 多实例编号、配置与日志隔离。
- 后台设备枚举、可调整界面区域、收发计数重置和 About 页面。
- Windows 精简文件图标与 Windows/Linux 单可执行文件绿色版打包结构。
- About 页面 GitHub/Gitee 仓库入口，以及内嵌的 Apache-2.0、NOTICE 和第三方声明离线查看。
- GitHub / Gitee 双源版本检查、Release 清单解析、镜像一致性校验和系统代理支持。
- 流式下载进度、文件大小与 SHA-256 校验、`.update/` 暂存和备用镜像回退。
- 单文件临时 updater、旧程序 `.bak` 备份、替换失败回滚、重启和启动后清理。
- 多实例安装保护、用户确认和上次更新失败提示。

## 待实机验收

| 优先级 | 功能 | 当前状态 | 完成标准 |
|---|---|---|---|
| P0 | Windows / Linux 跨平台支持 | **待实机验收** | Windows 已完成开发验证；Ubuntu 24.04 WSL2 已通过构建、测试、打包和启动存活检查。仍需在真实 Linux 桌面完成串口、USB 探针、J-Link SDK、权限、Wayland/X11 和绿色目录验收。 |
| P1 | 跨版本自动更新 | **部分验收** | 历史上 Windows 已完成 `0.1.4` 到 `0.1.5` 的真实下载、替换和重启。当前发布版本仍需回归；Linux 仍需验证真实升级，其他实例、只读目录、断网和回滚仍需补充现场验收。 |

完整验收范围见 [跨平台设计与验收](cross-platform.md)。

## 暂不支持

- **手动保存日志或显示内容**：依赖自动日志，避免现场人员忘记保存。
- **扩展发送高级编辑和批量操作**：当前能力已满足现阶段需求。
- **RTT 大范围内存扫描**：只支持指定 MCU 后连接 RTT。
- **安装包**：只提供单可执行文件绿色版，不生成 MSI、NSIS、AppImage 等安装程序。

## 更新规则

1. 新需求先加入本文件并写清验收标准。
2. 实现并通过检查后移入“已实现”，同时更新对应使用或开发文档。
3. 仅完成代码但未完成真实硬件验证的功能，应标记为“待实机验收”。
4. 已明确不做的功能保留在“暂不支持”，避免重复规划。
